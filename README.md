# Mono Minimal - Amazfit Active Max Watch Face

A clean,
grayscale watch face for
the **Amazfit Active Max**
(Zepp OS 5, 480×480 round screen).

## Features

- Large automatically updating 24-hour/12-hour (watch setting) hours and minutes.
- Horizontal real battery percentage at the top.
- Last measured heart rate, current steps, day of week, and date.
- Completely grayscale, black AMOLED background, no stray line to the left of the heart.
- No network, no third-party services, no JavaScript timers.

## Requirements

- Active Max with Zepp OS 5 (API level 4.2, device source IDs `10813697` or `10813699`).
- Node.js 18+ (Zeus CLI supports recent Node versions).
- Zepp developer account on the same Zepp account as the phone.
- Zeus CLI

## Build / install

### Zeus CLI

```sh
pnpm install --global @zeppos/zeus-cli` or
```

or

```sh
npm install --global @zeppos/zeus-cli`
```

Login to your Zepp developer account and build the watch face:

```sh
zeus login
```

Build and preview the watch face on your Active Max:

```sh
zeus build && zeus preview
```

In the Zepp Android app,
activate Developer Mode
(Profile → Settings → About → tap Zepp logo 7 times).

Open your Active Max page → Developer Mode → Scan,
then scan the QR code generated by `zeus preview`.

For simulator work,
launch a compatible 480×480 round device in the Zepp simulator and
run `zeus dev`.

Note that the simulator may not
provide an Active Max profile,
in which case use the actual device for the final test.

## Project layout

- `app.json`: Zepp watch-face manifest and explicit Active Max device IDs.
- `app.js`: Zepp OS app entry point.
- `watchface/active-max/index.js`: native time widget, battery, heart rate, steps, day/date.
- `assets/active-max/images/`: ready-to-build PNG assets (background, battery, digit glyphs).
- `scripts/generate_assets.py`: reproduces the bitmap assets using Pillow and system fonts. **You do not need Python to build the watch face**, because the PNG assets are included.

## Customization

- Change divider endpoints or position in `scripts/generate_assets.py` in `draw_background` (`y = 250`);
  it always draws with `(x0, y, x1, y)` to remain horizontal.
- Change positions and sizes in `watchface/active-max/index.js`.
- Regenerate assets with `./scripts/generate_assets.py`.
- Build via `zeus build` again.

## Notes / limitations

- Heart rate displays the **last sensor reading**;
  it does not force continuous monitoring.
  `--` means no valid reading is available.
- The watch face has a normal-display-only layout,
  not a separate Always-On-Display layout.
- The battery indicator uses the watch's **real** battery data.
- The bundled bitmap font glyphs are rendered assets;
  no font files are distributed.
